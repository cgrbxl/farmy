# Controlled disclosure solution

[UC-006](uc006/README.md) composes Wallet, a Local Folder Connector and Exchange with a separate synthetic recipient. Preview exact content, approve a bound manifest, deliver under separate authority and retain the recipient's receipt or explicit uncertainty. The command-line workflow and read-only monitor run on the synthetic macOS development profile.

Production recipient adapters, portable signed receipts, credential presentations and deployment packages remain future work. See the [case](use-cases/UC-006-controlled-disclosure.md) and [contract](../../contracts/uc006/README.md).
